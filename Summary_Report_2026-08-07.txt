JLU Whisperers - Daily Summary & Report
Date: 2026-08-07

=== WHAT WE ACCOMPLISHED TODAY ===

1. Interactive Polls
   - Added Poll and PollOption database models.
   - Built the frontend UI in the composer to create polls with dynamic options.
   - Implemented voting logic and persistence so votes aren't lost on refresh.
   - Added a misclick-prevention UI (radio buttons + 'Submit Vote') for safer polling.

2. Admin Dashboard & Stat Spoofing
   - Created a secure, admin-only dashboard (/admin).
   - Added a Moderation Queue to view flagged items.
   - Implemented admin controls to softly delete posts and ban users (which hides all their content).
   - Added an 'Edit Stats' feature allowing admins to manually override and spoof Views and Upvotes for any post.

3. Real View Tracking
   - Replaced randomized mock views with actual database-backed view counts.
   - Configured views to only increment when a user intentionally expands the replies on a post, preventing spam and over-counting.

4. Media Uploads (Images & Voice Notes)
   - Configured a local static/uploads directory and a secure file upload API.
   - Integrated a hidden native file picker for uploading images.
   - Implemented the browser MediaRecorder API to allow users to record and upload short voice notes directly from the composer.
   - Updated feed cards to beautifully render image previews and inline audio players.

5. Anonymous Direct Messaging (Instagram-Style)
   - Engineered a robust, anonymous messaging system with 'Message Requests' to prevent spam.
   - Users must discover others via the Feed (no global search) and send a request.
   - Built a dual-pane /messages interface featuring an Inbox (Active vs Requests) and a Chat window.
   - Recipients must explicitly 'Accept' or 'Decline' a request before full 2-way chat is enabled.

6. Bug Fixes & Stability
   - Fixed a critical Python syntax error (lowercase 'false' vs 'False') that crashed new guest sessions.
   - Fixed a frontend session handling bug that caused the app to break silently after a database wipe.

2. Incomplete Feed Features:
   - 'Add Emoji' button in the composer is currently a mocked, disabled button.
   - Nested Replies: Currently, you can only reply to a main post, not to other replies (no conversation threading).

3. Fake Moderation Queue:
   - The Admin Dashboard Moderation Queue is currently just displaying the 10 most recent posts, rather than actually filtering for 'flagged' content, because the AI integration is not yet built.

4. Media Storage & Cleanup:
   - Uploaded images and voice notes are stored indefinitely in 'static/uploads'. We have no cron job or cleanup script to delete media when a post is deleted by an admin, which will cause server bloat.
